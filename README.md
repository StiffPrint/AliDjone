# АлиДжон Store — веб-склад

Общая D1 база и вход через ChatGPT. Магазины: Островок, Центральный, Магазин 2.
Владелец определяется серверной переменной OWNER_EMAIL; при первом входе получает роль администратора.
Администратор добавляет сотрудников по email аккаунта ChatGPT и назначает роль / магазин.
Для частного сайта также необходимо предоставить сотруднику доступ в настройках размещения.

Менеджер получает только продажные цены. Проверка доступа выполняется для каждой операции на сервере.
Приёмки, перемещения с частичным подтверждением, продажи, возвраты и списания выполняются через документы.
Данные сохраняются с проверкой ревизии: конфликтующие изменения повторяются на актуальном состоянии.

Проверки: node --test tests/warehouse.test.mjs; npx tsc --noEmit.
Локальная SQLite база прежней версии не импортируется автоматически в облако.

## Разработка

Нужен Node.js 22.13 или новее.

```sh
npm ci
npm run dev
```

Для локального администратора создайте игнорируемый Git файл `.dev.vars`:

```text
OWNER_EMAIL=seedy@sites.test
```

Для локальной базы сгенерированная миграция находится в `drizzle/`. Порядок применения миграций и сборки описан в `DEVELOPMENT.md`.

В продакшене OWNER_EMAIL задаётся в защищённых настройках размещения. Самих секретов и данных склада в репозитории нет.
